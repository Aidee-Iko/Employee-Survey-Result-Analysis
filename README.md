# EMPLOYEE SURVEY RESPONSE 🧑‍💼👮‍♀️

## Summary
This analysis contains actual responses from an employee engagement survey conducted by Pierce County WA to uncover insights in employees satisfaction.
# Purpose
To discover how satisfied or dissatisfied employees are at their work environment. 
- Analyze satisfaction rate
- Identify pattern by department/role
- Gain insights into what causes satisfaction or dissatisfaction

# Tools
- Microsoft Excel- For designing interactive dashboard
- Power Query- Used for importing, transforming and loading data
- Pivot table- for summarizing, grouping, filtering,etc.
- File Format- .xlsx for report and .pdf for dashboard preview

# Data source
Dataset used for this analysis includes:
- Organization structure (departments and roles)
- Survey questions and responses

> _Note: This data was gotten from digitaley drive_

# Features & Highlights
 ### Problem Statement
The organization wants to understand employee sentiment, identify which areas employee agrees or disagrees with most, detect trends by department/role, and use these insights to improve employee satisfaction.
 ### Dashboard Goal
To provide insights 
 - Analyze trends
 - Uncover satisfaction/dissatisfaction level amongst employees 
 - Provide clear,actionable recommendations for enhancing workplace engagement.
###  Key Visuals
- Top Metrics Cards
  
 ⨀Total workers

 ⨀Directors(total number of directors)
 
 ⨀Managers(total number of managers)

 ⨀Supervisors(total number of supervisors)

 ⨀Staffs(total number of staff)




 - Bar Charts
   
 ⨀Survey questions vs responses


 - Pie Charts
   
 ⨀Top 3 disagreed questions

 ### Analysis insights
 - Discover trends and patterns
 - Insights on most disagreed question
 - Uncover ways for improvement

 ### Recommendations
 - Implement reward systems as a part of staff welfare
 - Encourage employee to be social by creating social events and fostering a sense of community.
 - Accountability amongst employees is needed
